# Example Documentation Output

This directory contains an example of documentation generated by the DeepWiki CLI tool.

## What's Inside

The `.repo-wiki` directory contains:

- **README.md**: Index page with links to all documentation pages
- **_structure.json**: Metadata about the wiki structure (pages, sections, relationships)
- **page-*.md**: Individual documentation pages with content

## Structure

```
.repo-wiki/
├── README.md           # Index page
├── _structure.json     # Wiki metadata
├── page-1.md          # Architecture Overview
├── page-2.md          # Getting Started
├── page-3.md          # Core Features
└── page-4.md          # API Reference
```

## Features Demonstrated

This example shows:

1. **Multiple Page Types**: Overview, getting started, features, and API reference
2. **Mermaid Diagrams**: Visual representations of architecture and data flow
3. **Code Examples**: Real-world code snippets with syntax highlighting
4. **Cross-References**: Links between related pages
5. **Structured Content**: Well-organized sections with clear headings

## How It Was Generated

This documentation was created using:

```bash
deepwiki /path/to/project
```

The CLI tool:
1. Analyzed the project structure
2. Used AI to determine the optimal wiki structure
3. Generated comprehensive documentation for each page
4. Created Mermaid diagrams where appropriate
5. Saved everything in the `.repo-wiki` directory

## Customization

You can customize the output by:

- Using `--comprehensive` for more detailed documentation (8-12 pages instead of 4-6)
- Setting `--language zh` for Chinese documentation
- Excluding directories with `--exclude-dirs node_modules,dist`
- Choosing a different LLM with `--provider openai`

See [CLI Documentation](../CLI_README.md) for all options.
